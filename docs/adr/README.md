# ADR（Architecture Decision Records）

重要な設計判断を1件1ファイルで記録する。ファイル名は `NNNN-短い題名.md`（例：`0001-item-id-from-name-key.md`）。

## 書式

```markdown
# NNNN. 題名

- 状態：提案 / 承認 / 置き換え（→ NNNN）
- 日付：YYYY-MM-DD
- 関連：FR-xxx、AC-xx、RISK-xx、PoC-xx

## 背景
## 選択肢
## 決定
## 根拠（PoCの結果・公式資料）
## 影響
## 見直し条件
```

公開リポジトリのため、利用者の実名・続柄・メールアドレス・秘密情報を書かない。
