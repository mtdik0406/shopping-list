# 0004. 入力検証のライブラリと Domain の規則の置き場所

- 状態：承認（ライブラリの最終決定は PR-5）
- 日付：2026-11-25
- 関連：FR-011、FR-013、FR-016、FR-019、FR-020、T-INV-01、T-INV-02

## 背景

名前の長さ・数量の範囲・正規化などの規則を、画面の入力・Firestore への書き込みの前・テストで同じように使いたい。規則が複数の場所に書かれると食い違う。

## 選択肢

1. Valibot
2. zod/mini

## 決定

- 第一候補は Valibot とする。PR-5 で zod/mini とビルドサイズを比べて決める。
- Domain の規則は純粋関数として1か所に書く。スキーマはその関数を呼び、規則を書き写さない。

## 根拠

- ビルドサイズを比べて決める。
- 規則を1か所にすれば、テスト（T-INV-01・02）と実装の食い違いを防げる。

## 影響

- PR-3 の Domain の純粋関数は、検証ライブラリに依存しない形で書く。

## 見直し条件

- PR-5 の比較で、zod/mini の方が小さいか、必要な機能が Valibot にないとき。
